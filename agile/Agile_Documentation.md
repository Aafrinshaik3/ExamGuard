# ExamGuard - Agile Documentation

## 1. Project Overview

**Project:** ExamGuard - Online Examination Monitoring and Integrity Analytics Platform

ExamGuard was developed using an Agile-oriented iterative approach. The project was divided into functional modules and developed incrementally, allowing individual components to be implemented, tested, integrated, and improved.

## 2. Agile Methodology

The project follows Agile principles by:

- Dividing the system into manageable features.

- Prioritizing important examination functionality.

- Developing modules incrementally.

- Testing functionality during development.

- Identifying and resolving implementation issues.

- Integrating completed modules into the final application.

- Continuously improving the system based on testing results.

## 3. Development Priorities

The development priorities were:

1. Basic project and application setup.

2. Authentication and user roles.

3. Examination functionality.

4. Automated examination monitoring.

5. Integrity and violation analysis.

6. Administrative dashboard and analytics.

7. Report generation.

8. Testing and documentation.

## 4. Agile Roles

### Development Team

The development activities covered:

- Application development.

- Backend implementation.

- Frontend implementation.

- Computer vision integration.

- Monitoring logic.

- Database integration.

- Integrity analysis.

- Testing.

- Documentation.

## 5. Definition of Done

A feature was considered complete when:

- The feature was implemented.

- It was integrated with the relevant application module.

- Basic functional testing was performed.

- Major errors were addressed.

- The feature was documented where necessary.

## 6. Product Increment

The final product increment consists of:

- Student examination interface.

- Administrator interface.

- Authentication and role management.

- Computer vision monitoring.

- Browser activity monitoring.

- Audio monitoring.

- Violation tracking.

- Integrity analysis.

- Database integration.

- Analytics.

- Report generation.

## 7. Continuous Improvement

During development, issues related to application flow, monitoring behavior, database operations, and integration were identified and addressed through iterative development and testing.

Future iterations can improve detection accuracy, scalability, browser compatibility, analytics, and deployment.
