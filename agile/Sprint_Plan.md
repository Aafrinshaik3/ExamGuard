# ExamGuard - Sprint Plan

## Sprint 1 - Foundation and Application Setup

### Goal

Establish the basic ExamGuard application structure and user management.

### Planned Work

- Flask application setup.
- Project structure.
- Database integration.
- User model.
- Authentication.
- Student and administrator roles.

### Expected Outcome

A functioning application foundation with role-based access.

---

## Sprint 2 - Examination Module

### Goal

Implement the online examination workflow.

### Planned Work

- Student examination interface.
- Question display.
- Answer handling.
- Examination submission.
- Result processing.

### Expected Outcome

Students can access and complete an online examination.

---

## Sprint 3 - Computer Vision Monitoring

### Goal

Implement camera-based examination monitoring.

### Planned Work

- OpenCV integration.
- Face detection.
- Face presence monitoring.
- Face absence detection.
- Multiple-face detection.
- Monitoring event recording.

### Expected Outcome

ExamGuard can monitor configured face-related examination events.

---

## Sprint 4 - Browser and Audio Monitoring

### Goal

Expand monitoring beyond camera-based events.

### Planned Work

- Tab-switch detection.
- Browser focus-loss detection.
- Audio-spike monitoring.
- Event thresholds.
- Violation recording.

### Expected Outcome

Multiple monitoring signals are integrated into the examination workflow.

---

## Sprint 5 - Integrity Analytics

### Goal

Convert monitoring events into structured integrity information.

### Planned Work

- Violation weights.
- Violation counting.
- Integrity calculation.
- Integrity classification.
- Administrative analytics.

### Expected Outcome

Administrators can review examination integrity information.

---

## Sprint 6 - Reporting and Final Integration

### Goal

Complete the system and prepare it for demonstration.

### Planned Work

- LangChain-based narrative reporting.
- Integration testing.
- Bug fixing.
- Documentation.
- Installation instructions.
- Agile documentation.
- Final GitHub repository preparation.

### Expected Outcome

A complete documented ExamGuard project ready for demonstration and repository submission.
